# 首頁地球探索

首頁參考 [NASA's Eyes](https://science.nasa.gov/eyes/) 以可操作 3D 畫面探索地球的方式，並參照站內「地球運動的地理意義」教材的經緯線和日照示意。星空、經緯線和光線由 CSS 與 three.js 程式繪製，沒有新增第三方 3D 素材。地球貼圖來源與授權見 [earth-texture.md](earth-texture.md)。

時間和日期使用既有 [NOAA 太陽位置近似公式](https://gml.noaa.gov/grad/solcalc/solareqns.PDF)；白點標示臺北，金色圓環標示太陽直射點，光線僅表示方向，不代表日地距離的比例。可拖曳地球或選擇臺北、北極視角；選擇時段或調整日期可改變日照。

瀏覽器模擬不等於實體裝置測試。iPhone、平板及專業科學內容審查仍為 **PENDING**。
