# 小白教育教材：公開目錄初步比對

比對日期：2026-10-31（臺北時間）。依小白教育[公開目錄](https://xbjiaoyu.com/#works)及本站的 54 個 Tongjiang Lab 單元與 3 個小白教育單元的標題、介紹和可取得的公開預覽做初步比對。這是選題清單，不是對每個模型內容的完整逐項審查。

當時公開目錄列出 550 筆，包含整合版、獨立版和 2D／3D 版本；同一教材會拆成多筆，不能將 550 筆視為 550 個不同實驗。目錄快照中 53 筆顯示可線上試用，其餘未顯示試用；不表示其餘內容不存在或均無法取得。部分下載或課件需登入，公開預覽與可供遷移的完整原始碼也不一定相同。

## 已在本站

- 平面鏡成像（含部分反射定律操作）、等高線與地形圖、原子結構與元素辨認。
